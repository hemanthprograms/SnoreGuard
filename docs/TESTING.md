# Testing

## Running the tests

```sh
make test
# Use a different simulator:
make test DESTINATION='platform=iOS Simulator,name=iPhone 15'
```

Or open `SnoreGuard.xcodeproj` (after `make project`) and press ⌘U.

## What the unit tests cover

`SnoreGuardTests` covers:

- `EventMerger`: overlap merging, the 10 s gap rule at its boundary, the 3 s minimum, threshold
  inclusiveness, peak confidence, unsorted input, incremental counting.
- `NightTotals` / `Night`: per-hour normalization, zero-length recordings, the 60 min/h cap, the 30
  minute rule.
- `RemedyAnalyzer` / `Statistics`: every label including both not-enough-data cases, the exact and
  Monte Carlo permutation p-values, and every summary sentence.
- `PlanEngine`: progress, suggestions, off-plan nights, completion, demo vs. real plan.
- `DemoData`: the demo tells the intended story (side sleeping "Likely helps", nasal strip "Might help",
  extra pillow "Not enough data yet", "Night 11 of 12").
- `FileSnoreDetector`: runs the real SoundAnalysis pipeline over the bundled recording and a generated
  tone (which must produce no snore events).
- `CSVExporter`: escaping and contents.

## Continuous integration

`.github/workflows/ci.yml` runs on every pull request and on pushes to `main`. It generates the
Xcode project with XcodeGen and fails on any warning or error in the project's own sources
(`Tools/check_xcodebuild_warnings.sh`).

| Job | What it does |
| --- | --- |
| Build and test on an iPhone simulator | Builds the app and runs `SnoreGuardTests`, using the first Xcode on the runner that has an iPhone simulator installed (Xcode 26.1 at the time of writing). |
| Build with Xcode 16 | Compiles the app and tests with Xcode 16 (Swift 6.0) for the generic simulator, so the code keeps building on the older toolchain. |

Both jobs upload their `xcodebuild` logs as artifacts.

## Testing detection by hand

On the Start night screen, **Analyze sample recording** runs the real detection pipeline over the
bundled clip, and **Import an audio file…** runs it over any recording you choose. Both go through the
same code path as the microphone.

To test on real snoring without an iOS 17 phone, record a night with Voice Memos, AirDrop it to the Mac,
drag it onto the Simulator (it lands in Files) and import it. The Simulator also listens through the
Mac's microphone, so Start night works there too.

The bundled `SampleSnoring.m4a` is synthetic, generated by `Tools/make_sample_audio.py`. Apple's
model scores it as snoring (peak confidence 0.84, both snoring stretches found as events), but a real
night is the honest test.
